## 一、键位与操作

| 操作 | 按键 | 说明 |
|---|---|---|
| 移动 | **鼠标点击地面** | 点击哪里走哪里；按住拖动会进入自动奔跑 |
| 移动（备用） | **WASD** | 直接控制移动 |
| 攻击技能 1 | **鼠标左键** | 装备在左键槽的攻击技能（默认火弹术） |
| 攻击技能 2 | **鼠标右键** | 装备在右键槽的攻击技能 |
| 强制施法 | **按住 Shift + 点击地面** | 朝该点方向放技能（不点怪也能放） |
| 被动技能 | **数字键 1 / 2** | 装备在被动槽的技能（如光盾/生命虹吸） |

**左键的双重职责**（源码 `AbilityInputTagPressed` 的逻辑）：
- 鼠标点到**敌人**身上（高亮）→ 再按左键 = 朝敌人施法
- 鼠标点到**地面** → 按左键 = 移动过去
- 按住 **Shift** 再按左键 = 无论指哪都施法

## 二、菜单从哪打开（不用按键，点屏幕）

主界面（游戏内）屏幕上有两个按钮（就在血球/蓝球那一排旁边）：
- **SPELLS** → 打开技能菜单
- **Attributes** → 打开属性菜单

### 技能菜单用法（升级/装备技能的核心循环）
1. 打怪得经验 → 升级获得**技能点数**（屏幕会提示）
2. 点 SPELLS → 左侧技能列表里，等级达到要求的技能会亮起（状态 Eligible）
3. 点选技能球 → 点 **Spend Point / 加号** 花技能点解锁（Eligible → UnLocked）
4. 解锁后**点住技能球拖到右侧槽位**（鼠标左键 / 鼠标右键 / 被动槽）装备
5. 装好的技能立即生效（Passive 装上即触发光环效果）

### 属性菜单用法
- 升级还获得**属性点数** → Attributes 菜单里每行有加号按钮
- 四项主属性：力量(物伤+物抗)、智力(法伤+法抗)、坚韧(护甲+护甲穿透)、活力(生命上限)
- 次要属性由主属性自动派生（暴击/格挡/回蓝等），手动加不了

## 三、怎么推进游戏

1. **主菜单** → Play → 读档界面：空槽是"新游戏"，选中槽 → PLAY 进入游戏（默认地图 StartupMap）
2. **杀怪升级**：地图上的怪（哥布林等）用技能打，击杀掉落经验/药水/装备球
3. **存档点**：地图上的发光石台，走过去自动保存进度（等级/技能/位置），死亡后从这复活
4. **换图**：找地图里的**入口传送门（MapEntrance）**走上去切到下一张图——项目里有 Dungeon → Dungeon1 → Dungeon2 → Dungeon3
5. 读档界面 DELETE 删除存档（有二次确认弹窗），QUIT 退出

## 四、地图、传送卡墙与刷怪（实测记录）

### 各地图的用途
| 地图 | 用途 | 内容完整度 |
|---|---|---|
| MainMenu / LoadMenu | 主菜单/读档界面（UI 场景） | 完整 |
| StartupMap | 新游戏起始图 | 有战斗区 |
| Dungeon / Dungeon1~3 | 演示"存档-切图-回读世界状态"的关卡链 | 只有第一张铺了怪；Dungeon1 有 5 个存档点无怪；Dungeon2/3 有传送门实例 |
| EQS_TestingMap | AI 寻路测试图（开发用） | 不进游戏流程 |

### 传送落点卡墙的根源与修复
`GameModeBase::ChoosePlayerStart`（DuraGameModeBase.cpp:206）：收集目标图全部 PlayerStart → **默认取第 0 个** → 仅当某个 PlayerStart 的 `PlayerStartTag` 等于存档的 PlayerStartTag 时才选它。
所以传送门的 `Destination Player Start Tag` 在目标图里**没有配对**的 PlayerStart 时，会盲落到第一个 PlayerStart（可能在墙里）。

- **立刻脱困**：游戏内按 `'`（单引号）开控制台 → 输 `fly` 飞出去 → 输 `walk` 落地
- **根治**：目标图开阔处放一个 PlayerStart（Place Actors 面板搜 Player Start）→ Details 填 `PlayerStartTag`（如 `Dungeon1Enter`）→ 传送门的 `Destination Player Start Tag` 填**一模一样的值**。两边对上即精确落点。
- 或者最简单：直接把目标图里那个卡墙的默认 PlayerStart 拖到开阔地。

### 给空地图加怪（工具都是现成的）
- `DuraEnemySpawnPoint`：点刷怪。拖进场景 → Details 的 `Enemy Class` 选敌人蓝图（哥布林等）→ 玩家靠近激活
- `DuraEnemySpawnVolume`：区域刷怪。设定范围 + 要刷的怪 → 玩家进入区域触发

## 五、视角与小地图（设计说明）

- 相机在角色蓝图 `BP_DuraCharacter` 内（SpringArm + Camera），**固定俯视角**——这类游戏是暗黑破坏神/流放之路式的俯视角 ARPG，设计上就不手动转视角：鼠标指哪走哪，角色朝移动方向转身。不是做坏了。
- 小地图：项目**未实现**（不是隐藏功能）。想要属于新功能开发（HUD 上画一张按角色位置更新的圆盘图）。
- 想改成可旋转的第三人称视角：SpringArm 开 `Use Pawn Control Rotation` + 新增鼠标输入轴控制 yaw——会改变玩法类型，属于进阶练习。
