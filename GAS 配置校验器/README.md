# GAS 配置校验器 —— 总目录

> 为 GAS_Dura 项目开发的编辑器工具：一键扫描全部技能/效果/数据资产，自动发现配置错误。
> 本文件夹是**完整的过程文档 + 原理讲解**，既是使用手册，也是教程。

---

## 这个工具是什么（30 秒版）

- **给谁用**：配 GAS 技能的策划/程序（主要是你自己）
- **干什么**：点一下「开始扫描」，0.4 秒扫完 58 个 GAS 资产，列出所有配置错误
- **特点**：只报告不修改（安全）、中文人话报错（说清后果和改法）、双击跳转资产、可导出 Markdown 报告、支持控制台命令/命令行无头运行
- **技术**：C++ Editor 模块（DuraEditor）+ Slate 界面 + UEditorSubsystem + AssetRegistry

## 快速使用

| 方式 | 操作 |
|---|---|
| 编辑器界面 | 主工具栏点「GAS 校验」（或 窗口 菜单 → GAS 配置校验器）→ 点「开始扫描」 |
| 看结果 | 列表按 错误→警告→提示 排序；顶部过滤下拉可切"仅错误"；搜索框按资产/规则名过滤 |
| 跳转修复 | **双击任意结果行** → 打开对应资产并定位到内容浏览器 |
| 导出报告 | 点「导出报告」→ `Saved/GASValidator/GAS校验报告_时间戳.md` |
| 命令行/CI | `UnrealEditor.exe Dura.uproject -ExecCmds="Dura.GASValidatorOpen,Dura.GASValidate"` → 结果在日志和报告文件里 |
| 控制台 | 输出日志的 Cmd 输入框：`Dura.GASValidate`（扫描+导出）、`Dura.GASValidatorOpen`（开面板）、`Dura.GASValidatorExport`（导出） |

## 代码在哪

```
Source/DuraEditor/            ← 全部工具代码（游戏运行时代码零改动）
├── DuraEditor.Build.cs       模块依赖
├── DuraEditor.h/.cpp         模块入口：标签页 + 工具栏按钮 + 控制台命令
├── GasValidatorTypes.h       数据结构（问题/结果）
├── GasValidatorCore.h/.cpp   ★ 校验核心：五步流水线 + 16 条规则
├── GasValidatorSubsystem.h/.cpp  编辑器子系统：扫描入口 + 结果 + 报告导出
└── SGasValidatorPanel.h/.cpp Slate 面板：列表/过滤/搜索/跳转

Dura.uproject                 ← 仅新增 DuraEditor 模块声明
```

## 一句话备忘

> 配置错误不怕发现晚，就怕**静默失败**——技能放不出、不掉血、不耗蓝，引擎一声不吭。
> 这个工具的价值：把 GAS 的静默失败变成配置阶段的显式报告。
